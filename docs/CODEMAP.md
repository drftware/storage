# Code map

Where code lives, one line per module: path, then what it owns. Read only the rows your ticket
touches. This file is read on demand, never at session start; keep each row to one line.

| Path | Owns |
| --- | --- |
| `default.project.json` | Rojo tree (JSON with comments): Brix → ReplicatedStorage.Brix, `src/shared` → ReplicatedStorage.Shared, `src/server` → ServerScriptService.Server, `src/client` → StarterPlayerScripts.Client; streaming and Lighting settings with what each does to the player |
| `vendor/brix/` | Brix, a git submodule pinned at `4c21b5f` (docs/FRAMEWORK.md) |
| `src/shared/StorageUnit/init.luau` | The package: Curtain, Motion, RollUpDoor, ShutIn, UnitKit, Specs |
| `src/shared/StorageUnit/Curtain.luau` | Pure roll-up kinematics: rise → every slat's frame and the drum angle (port of `art/unit/curtain.py`) |
| `src/shared/StorageUnit/Motion.luau` | Pure door timing curves per action, targets, the replicated motion string |
| `src/shared/StorageUnit/RollUpDoor.luau` | Server `play`/`setLocked`/`rise` and the DoorCollider (`ColliderDepth`, `fitCollider`); `spec`; client `watchTagged` rigs, the lazy slat chain, posing |
| `src/shared/StorageUnit/UnitKit.luau` | One-time `prepare` of an imported unit; `paint`, `number`, `dropWall` |
| `src/shared/CorridorKit/init.luau` | The corridor kit's pieces, its walls and its hall light fixture: `template`, `frame` (a piece's or junction's from its floor part's own frame; a wall's or the fixture's from the facade's or the lens's box), one-time `prepare` of an inserted model, `place` a copy into a floor, `wall` a plain wall, short wall or dead end painted like the floor's units, `junction` a corner, T or cross with its walls, `hang` a fixture (returns its lens and eye); templates at `ReplicatedStorage.Corridor.<Name>` (D-020 to D-023) |
| `src/shared/CorridorKit/Specs.luau` | Generated by `art/corridor/build.py`: the kit's heights, joist beat, each piece's length, colliders and triangle counts; each wall's width, collider and triangles; each junction's size, arms, walls (name, frame), colliders and triangles; the fixture's lens height and size, reach and triangles |
| `src/shared/HallLight.luau` | The hall fixture's light (D-015, D-017): the tube's height, cone, brightness and short reach, the fill at door height, the dust haze under a lit tube (D-018; its emitters tagged `HallLight.HazeTag`, their rate 0, D-019), the weaker far tube, the exit sign's glow (hung off the wall it lights), the line under a door; `light` (tube and fill) and `exitSign` tag each light `HallLight.Tag` with its lit brightness (D-016); `eye` sets a fixture's sensor dome to Watching, Seen or Blind (D-021) |
| `src/shared/Pace.luau` | Pure: something that happens at a steady rate, stepped by frame time; a hitch fires it once and drops the backlog (the haze's puffs) |
| `src/shared/StorageUnit/ShutIn.luau` | Pure: who a shut door hides from whom (inside the unit's room or not, door shut or not), and `light`, how much hall light reaches you shut in as the door lifts; `tests/shutin.spec.luau` |
| `src/shared/StorageUnit/Specs/` | Generated per size by `art/unit/build.py --stage export`; never hand-edit |
| `src/server/init.server.luau` | The server's Brix Host: declares its systems, steps them on Heartbeat, stops them on close |
| `src/server/DevCorridor.luau` | Studio-only system: a test hall of nine real units on three straight kit pieces under three kit fixtures (weak, lit, dead), plain walls past the last units, a dead end at the spawn's end and a turn at the far end (a T, a dead-end arm, a corner into a dark hall; plain blocks and bare tubes if the place lacks the kit), with a prompt per door action, and the streaming test (Go far, Come back) |
| `src/client/init.client.luau` | The client's Brix Host, stepped on RenderStepped |
| `src/client/DoorView.luau` | Client system: draws every unit's door (starts and stops `RollUpDoor.watchTagged`) |
| `src/client/BehindDoors.luau` | Client system: stops drawing anyone a shut door stands between you and (`LocalTransparencyModifier`), so arms never show through, and hides their name tag (`DisplayDistanceType`); shut in, dims the hall's lights on your screen and draws the line under the door (D-016) |
| `src/client/FreeCursor.luau` | Client system, mouse players only: Left Alt frees the mouse and takes it back (a `Modal` button), draws the cursor only while it's free (`MouseIconEnabled`), and the once-a-session "Alt Cursor" hint; its feel numbers at the top |
| `src/client/HallHaze.luau` | Client system: emits each lit tube's dust puffs on this screen at `HallLight.HazeRate`, so the haze is as thick at low graphics as at full quality, and bursts a tube already lit when it streams in (D-019) |
| `tests/*.spec.luau` | Lune specs (curtain against Python's fixture, motion timings, who a shut door hides, the haze's pace, the corridor kit against the haze, its own tiling, the tuned tube and the units' walls); `tests/fixtures/` from `art/unit/fixture.py` |
| `art/unit/` | The unit's Blender pipeline; its README is the asset's doc |
| `art/unit/out/` | Built outputs: `StorageUnit_M.fbx`, `textures/` (five sets), `M/unit.blend` |
| `art/corridor/` | The corridor kit's Blender pipeline (pieces, walls and the fixture on the unit's textures); its README is the kit's doc. `out/Corridor_<Name>.fbx`, `assets.json` |
| `art/sheets/` | Look sheets and door animations |
| `.mcp.json` | Starts Studio's MCP server so a session can drive Studio (`docs/STUDIO.md`, Tools) |
| `scripts/check.sh` | Format, lint, strict types, Rojo build, Lune tests |
| `scripts/upload_art.luau` | `lune run scripts/upload_art [dry] [Key...]`: uploads each changed FBX (the unit, the corridor kit's pieces, walls and fixture), or only the named ones, through Open Cloud, records IDs in its folder's `assets.json` (D-010) |
| `scripts/lib/OpenCloud.luau` | Open Cloud upload and poll; reads the key from the git-ignored `.config/.env` |
| `art/unit/assets.json` | Upload manifest: size → FBX hash and Model asset ID. Written only by the upload script |
| `docs/art/` | In-game screenshots per ticket |
| `scripts/art.sh` | Rebuild the unit's art (`SIZE=L scripts/art.sh geo export` for another size); `scripts/art.sh corridor` rebuilds the corridor kit |
| `scripts/hooks/require-handoff.sh` | Stop hook: blocks ending a turn without a written, committed handoff |
